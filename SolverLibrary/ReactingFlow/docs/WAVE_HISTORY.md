# 反応波の位置・速度履歴（Fortran、1D）

長時間反応波検証のための任意診断。未指定なら従来の入力・出力・計算を維持する。
検出器は圧力分布を読むだけで、保存量・時間刻み・境界条件を変更しない。
独立ReactingFlowの`rf_flow1d`用であり、NSEの後処理やcase.yamlの仕様は変更しない。

## 設定例

既存入力の`&flow1d ... /`内に追加する：

```fortran
 wave_output='wave_history.csv',
 wave_xmin=0.00025, wave_xmax=0.0008,
 wave_min_pressure_jump=10000,
```

上記の長さ[m]は0.002 m領域のZND比較試験向け。実際の領域・波面移動範囲に合わせる。
相対出力パスは**入力ファイルのディレクトリ基準**。既存ファイルは上書きせず拒否する。
再実行では別名を使う。親ディレクトリは事前に作成する。

- `wave_output=''`：既定、診断なし。
- `wave_xmin=0`、`wave_xmax=-1`：既定、全領域。-1は領域長へ置換する。
- `wave_min_pressure_jump=1`：既定1 Pa。正の有限値のみ。
- 出力を指定せず探索設定だけを変更した入力は拒否する。

通常の実行例（FrameWorkルート、機構ファイル作成は[反応器手順](REACTORS.md)参照）：

```powershell
.\build\reactingflow-fortran-release\rf_flow1d.exe h2o2.rf my_flow.in flow.csv
```

```bash
./build/reactingflow-fortran-release/rf_flow1d h2o2.rf my_flow.in flow.csv
```

## 検出と速度

セル中心圧力p_iに対し、探索区間内の内部セル境界x=iΔxで

```
J_i = abs(p_(i+1)-p_i)
i_peak = argmax J_i
x_wave = i_peak * Δx
v_wave = (x_wave(t_n)-x_wave(t_(n-1))) / (t_n-t_(n-1))
```

とする。同値の最大値は左側を選ぶ。最大圧力差がしきい値未満なら未検出。
しきい値は勾配Pa/mではなく**隣接セル間の圧力差Pa**なので、格子変更時には再検討する。
速度は右向きを正とし、連続した2回の検出時だけ有効。
未検出を挟んだ差分から速度を計算しない。

CSV列は`step,time,position,speed,pressure_jump,detected,speed_valid`。
時間[s]、位置[m]、速度[m/s]、圧力差[Pa]。論理値はT/F。
未検出時のpositionとspeed、および速度未確定時のspeedは0を格納するが、
**0が実測値とは限らないため、必ず論理列を確認する**。
pressure_jumpは探索内の最大圧力差を保持する。
初期時刻から各受理ステップ・最終時刻を記録する。`write_every`には依存しない。
正常終了時だけ末尾に`# SUCCESS`が付く。

位置は格子境界刻みなので、瞬時速度にはΔx/Δt程度の量子化変動が生じ得る。
定常伝播速度を評価するときは連続して検出された十分長い区間でx(t)を直線近似し、
格子・時間刻み・探索範囲依存性も調べる。

## 制限と検証範囲

- 最大圧力差を波面**候補**とする診断であり、衝撃波と急な膨張・別の圧力波を物理的に識別しない。
  複数の強い波がある場合には探索範囲を限定する。同一波面の追跡ID機能はない。
- 波面が範囲外に出ると、範囲内の別の強い構造へ切り替わる可能性がある。
  長時間試験では保存した分布との照合が必要。
- 速度はソルバーの座標系での値。衝撃波固定ZNDではほぼ0が期待値で、
  実験室座標でのCJ速度を直接出す機能ではない。座標軸の向きも含めて変換する。
- Fortran単体試験：左右移動、初回速度無効、見失い、再捕捉、範囲外・弱い波の除外。
- 実行試験：初期／最終時刻・ステップ履歴、ファイル保護、未検出フラグ、無効入力、
  診断あり／なしで全場出力が厳密に一致することを確認。
- ZND比較試験にも履歴出力と最終波面位置判定を組み込む。

この診断の追加は長時間自走デトネーション検証の完了ではない。
実計算と独立基準の比較・収束確認は[CFD反応波検証](CFD_WAVE_VALIDATION.md)で管理する。
