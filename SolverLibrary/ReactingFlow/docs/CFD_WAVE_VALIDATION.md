# CFD反応波検証（2026-09-29）

対象：独立ReactingFlow、CPU逐次、1D反応Euler、SSPRK3＋Strang化学分割。
**一次精度・MUSCLとも限定した短時間反応波試験に合格。**
MUSCLの物性下限付近の停止は、一様状態保持と温度復元精度の修正で解消した。
以下の停止診断は修正前の記録として残す。長時間自走波の検証完了を意味しない。

## MUSCL修正と最終結果

1. 傾きが厳密にゼロの場合、面の保存量をセル保存量のまま保持する。
   不要な保存量→温度等→保存量の往復による誤差を持ち込まない。
2. SSPRK3の重み付き和を代数的に等価な増分形に変更する。
   `b=q+((a-q)+dt*rhs)/4`、`result=q+(2/3)*((b-q)+dt*rhs)`とし、
   右辺がゼロの一様流では更新が厳密にゼロになるようにする。
   元の形式ではdtを縮めても凸結合の丸め誤差が消えない。
3. 温度復元の旧相対残差1e-11は、NASA端点の受入れ幅より大きいエネルギー誤差を
   許していた。残差基準を熱力学量スケールの機械精度に近づけ、端点近傍も
   既存の丸め誤差帯内で端点へ復元する。物性範囲外の受入れ幅は広げない。

Rusanov流束、CFL条件、再試行回数、反応機構、試験条件、合格基準は維持。
保存量のクリッピング、物性温度範囲の外挿、MUSCLから一次精度への切替は行っていない。
追加した単体試験では、NASA下限・2044 m/sの一様流を100ステップ更新し、
保存量がビット単位で不変であること、ゼロ傾き面の保存量がセルと一致することを検査する。

最終版MUSCLの圧力誤差Epは128セルで0.04042793580、256セルで0.02120296618。
細分化で誤差が減少し、256セルで既存基準3%未満に到達。正圧力・波面位置・保存量収支も合格。
Release回帰86件は全て合格。Debug/ReleaseのFortran単体試験はそれぞれ4件全て合格。

## 条件と独立基準

- Cantera 3.2.0 `h2o2.yaml`、H2:O2:N2=2:1:3.76（モル比）。
- 上流300 K、101325 Pa、上流凍結音速基準Mach 5。
- 衝撃波固定・下流向き座標。上流速度2043.8708649 m/s。
- 領域長0.002 m、初期衝撃波位置0.0005 m、終了時刻2e-7 s。
- 左：超音速`reacting_inlet`、右：既存の局所線形`characteristic`流出。
- 粘性・熱伝導・種拡散なし。火炎構造や輸送モデルの検証ではない。
- Cantera物性・反応速度とSciPy Radauにより定常ZNDを独立積分。
  衝撃波直後は凍結Rankine–Hugoniot条件を解く。
  共通の反応機構データを使うが、CFDソルバーの積分結果を正解として使わない。
- ZNDセル中心値を初期化に使用（厳密なセル体積積分値ではない）。
  衝撃波はセル境界に一致。比較するのは衝撃波固定定常分布の有限時間保持性能。

圧力誤差を

```
Ep = mean_i(abs(p_CFD(i,tend) - p_ZND(x_i))) / max_i(p_ZND(x_i))
```

と定義。128→256セルでEpが減少し、256セルでEp<0.03を要求する。
波面は最大隣接圧力差で検出し、初期位置から2セル幅以内を要求。
正圧力と、境界流束込みの質量・運動量・全エネルギー・元素の既存相対収支誤差<1e-8も検査する。

## 一次精度Rusanovの結果

| セル数 | max_dt [s] | 化学rtol | Ep |
|---:|---:|---:|---:|
| 128 | 2e-9 | 1e-9 | 0.03767106168 |
| 256 | 2e-9 | 1e-9 | 0.02624286333 |
| 128 | 1e-9 | 1e-9 | 0.03767357044 |
| 128 | 2e-9 | 1e-10 | 0.03767106125 |

化学の標準絶対許容誤差は組成1e-16、温度1e-8 K。
厳密化ではそれぞれ1e-17、1e-9 Kへ同時に変更。
実際の流体刻みはmax_dtとCFL制約などの最小値であり、固定刻みではない。

同じ128セルの標準結果に対する圧力差
`mean(abs(p_variant-p_standard))/max(p_standard)`は、
max_dt半減で2.73375e-6、化学許容誤差厳密化で7.15113e-10。
いずれも今回の判定基準1e-3未満。空間誤差がこれらの感度より大きい。
ただし2格子だけから漸近収束次数を断定しない。時間積分誤差とStrang分割誤差は
この試験では合算された感度であり、個別の次数検証ではない。

## 修正前のMUSCL停止診断（履歴）

128セルのEpは約0.03997。256セルでは時間刻みの再試行30回で停止。
化学を無効にしても停止するため、化学積分単独の問題ではない。
反応なし診断の最後の保存時刻は1.3766684549e-7 s（440ステップ）。
最終棄却時の刻みは約2.37326e-18 s。

診断されたセル60では、最小部分密度は0、全密度は約0.8494721 kg/m3。
内部エネルギーとNASA共通下限300 Kでの値は次の通り：

```
e            = -116671.84776708763 J/kg
e_NASA_min   = -116671.84776703164 J/kg
e-e_NASA_min = -5.5995769798755646e-8 J/kg
```

エネルギーの絶対値が負なのは生成エネルギーの基準によるもので、負圧を意味しない。
元の反応ありMUSCL計算でも同じ下限判定による停止を再確認した。
この場合の最初の不適格セルは1、e=-116671.84776779707 J/kg、
下限値=-116671.84776774107 J/kgで、差は同じ-5.59957698e-8 J/kgだった。
確認された棄却理由は、内部エネルギーが物性下限許容域をわずかに外れることである。
極端に小さいdtでも解消せず、丸め・熱力学反転精度・MUSCL更新と下限判定の整合性を
調べる必要があると判断し、上記の修正・再試験を行った。
物性下限を拡張したり、エネルギーをクリッピングしたりしていない。

## 再実行

比較環境：Python 3.12、NumPy 2.5.3、SciPy 1.18.1、Cantera 3.2.0。
Fortran本体の[ビルド手順](REACTORS.md)を先に行う。
FrameWorkルートから、PowerShell：

```powershell
$env:RF_FORTRAN_BUILD = (Resolve-Path build/reactingflow-fortran-release).Path
python -m unittest discover -s SolverLibrary/ReactingFlow/tests -p test_reactive_boundaries.py -k znd -v
```

Linux bash：

```bash
export RF_FORTRAN_BUILD="$PWD/build/reactingflow-fortran-release"
python3 -m unittest discover -s SolverLibrary/ReactingFlow/tests -p test_reactive_boundaries.py -k znd -v
```

一次精度試験だけなら`-k first_order`、MUSCLだけなら`-k stationary`。
MUSCL試験も通常の合格必須回帰試験として維持する。
`build/reactingflow-wave-diagnostic`のCSV・ログはローカル診断用成果物で、ソースの一部ではない。

## 残る検証

追加格子・異なる条件での頑健性と収束、長時間の波面速度と反応帯、
時間／分割誤差の独立検査、CJ極限・自己維持デトネーション・異なる機構・境界反射。
今回の過駆動波の短時間検査だけで、これらやR4全体の完了は宣言しない。

修正前の回帰結果は86件中85件合格、MUSCL反応波1件不合格だった。
修正後の結果は冒頭の「MUSCL修正と最終結果」を参照。
