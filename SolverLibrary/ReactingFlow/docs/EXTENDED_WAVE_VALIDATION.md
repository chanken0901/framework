追記：[同一格子幅の下流境界距離比較](BOUNDARY_DISTANCE_VALIDATION.md)も1.0 µsで合格。
ただし初期音響伝播時間は約4.60 µsであり、境界反射が波面へ戻った後の検証は残る。

修正後の検証：通常回帰89件中88件合格・1件スキップ（延長試験）、
延長試験は別実行で1件合格。Debug/ReleaseのFortran CTestはそれぞれ5/5合格。
通常回帰の短時間MUSCL試験の圧力誤差は128セル1.0969%、256セル0.5646%。

化学種MUSCLの組成和補正先を変更した結果、**512セルの延長試験が既存の全基準に合格した**。
修正原因と離散残差は[Fortran残差診断](FLOW_BALANCE.md)を参照。

これは自走CJデトネーションの長時間検証とは異なる。

下流全反応帯・境界の十分長い時間の安定性まで保証しない。

## 比較内容と判定基準

128・256・512セルを比較する。粗い格子は解像度不足の診断用で、
精度目標は最も細かい格子に適用し、圧力誤差は細分化ごとに減少することを要求する。

- 圧力L1差／基準最大圧力：5%未満（従来0.2 µs試験の3%基準は変更しない）。
- 温度L1差／基準最大温度：5%未満。
- H2O質量分率の絶対L1差：0.02未満。
- 波面位置のずれ：領域長の5%以下、全履歴で波面候補を検出。
- 後半0.5〜1.0 µsの位置を時間に対して直線近似した移動速度：
  絶対値／上流流入速度が5%未満。衝撃波固定座標では理想値は0。
- 正圧力、正常終了、境界流束込みの質量・運動量・全エネルギー・元素収支の
  既存相対誤差が1e-8未満。

比較は初期に与えた独立Cantera/Radau ZNDのセル中心値に対して行う。
数値拡散、波面移動、境界誤差、流体・化学分割誤差を全て含む試験であり、
単独の原因をこの誤差だけから断定しない。物性や保存量をクリッピングして合格させない。

## 実行

時間のかかる追加試験なので通常の回帰ではスキップし、明示的に有効化する。
必要パッケージはNumPy、SciPy、Cantera、PyYAML。
`RF_WAVE_ARTIFACTS`は任意。指定すると各条件の機構・初期分布・入力・全場出力・
波面履歴・ソルバーログを保存する。既存の同名条件ディレクトリは上書きしないため、
再試験時は新しい保存先を指定する。保存しない場合は通常の一時ファイルを用いる。

PowerShell（FrameWorkルート）：

```powershell
$env:RF_FORTRAN_BUILD = (Resolve-Path build/reactingflow-fortran-release).Path
$env:RF_LONG_WAVE_TESTS = '1'
$env:RF_WAVE_ARTIFACTS = "$PWD/build/extended-wave-run01"
python -m unittest discover -s SolverLibrary/ReactingFlow/tests -p test_reactive_boundaries.py -k extended -v
```

Linux bash：

```bash
export RF_FORTRAN_BUILD="$PWD/build/reactingflow-fortran-release"
export RF_LONG_WAVE_TESTS=1
export RF_WAVE_ARTIFACTS="$PWD/build/extended-wave-run01"
python3 -m unittest discover -s SolverLibrary/ReactingFlow/tests -p test_reactive_boundaries.py -k extended -v
```

全回帰に含める場合は`-p ... -k extended`を外す。
計算本体と波面診断はFortran。Pythonは独立基準生成・試験実行・比較・成果物保存のみ。

保存した条件を再実行するときは、`m.rf`、`case.in`、`initial.rf`だけを新しい
作業ディレクトリへコピーし、`rf_flow1d m.rf case.in flow.csv`で実行する。
`wave.csv`と`flow.csv`を同じ場所に残したままでは上書き防止により停止する。

## 初回確認

2026-09-30、128セルは計算自体は正常終了したが、圧力誤差12.0953%、
温度誤差14.1406%、H2O絶対L1差0.0348001、後半波面速度約−141.85 m/s。
位置ずれは約0.21875 mmで、精度目標には未達。精度目標は緩めず細分化を調べる。

境界の切り分けとして256セルで右端を同じ参照状態のDirichletに変更したところ、
圧力誤差は11.9299%、最終波面位置0.296875 mmだった。
特性境界から変更しても大幅な改善はなく、流出境界だけが主因とは断定できない。
セル中心初期分布で標本化した発熱ピークは初期衝撃波から約0.15234 mm下流にある。
この距離だけで誘導帯・数値的に広がった衝撃波の解像度が十分とは判断しない。

ローカル成果物は`build/reactingflow-extended-wave-refinement/`の条件別フォルダに保存。
境界比較は`build/reactingflow-extended-outlet-dirichlet/`に保存した。
入力・機構・初期分布・全場出力・波面履歴・ログを含む。
通常回帰は88件中87件合格・延長試験1件を意図したスキップ。
延長試験は別途明示的に実行し、不合格を確認した。通常回帰の成功で上書きしない。
今回、Fortranの数値方式・物性判定・従来の短時間試験基準は変更していない。

## 残課題

初期流束整合性・反応源・刻み依存性を確認し、化学種再構築の不要な一次精度化を修正した。
残差と延長試験は改善したが、全条件の頑健性を証明したわけではない。判定値は緩和していない。
延長試験の格子収束、より長い時間、境界までの距離依存性、CJ極限・自己維持波、
異なる機構、時間／化学分割の独立収束、多次元・ノズルはR4の残作業として区別する。
