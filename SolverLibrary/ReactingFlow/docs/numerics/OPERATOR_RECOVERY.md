# CFD試行段の物性・境界範囲チェックと再試行

2026-10-01。従来の[化学再試行](CHEMISTRY_RETRY.md)を拡張した。
本体はFortran。入力形式や許容誤差の既定値は変更しない。

## 対応範囲

- CFDセル化学積分中の非有限Newton試行、NASA温度範囲外の試行／採用候補。
- SSPRK試行段およびStrang全段終了時の輸送テーブル温度範囲外。
- 特性流出／反応流入の試行境界における逆流、音速条件不整合、非正圧など。
- 特性流出で構成した温度がNASA範囲外になる場合。

これらはCFD試行を失敗として返し、**全Strangステップを元の保存変数から再実行**する。
刻みは半分、上限は従来どおり30試行。失敗時の境界流束積算は採用しない。
最初から不正な入力・不正な参照状態・不正なテーブル構造は再試行せずエラーにする。
物性範囲の拡張、温度や保存変数のクリッピング、反応許容誤差の緩和は行わない。
物理的にモデル範囲を越えて発熱・冷却し続ける場合、再試行は解決策にならず最終的に停止する。

DVODEのRHSにはエラー戻り値がないため、回復対象の範囲違反をコンテキストに記録し、
呼出しが返るまでは有限なゼロ微分を返す。この印が一度でも立った積分結果は、
DVODEの終了コードによらず全て破棄する。ゼロ微分の結果を物理解として採用しない。
独立0D反応器の厳格な停止動作は維持する。

## 検証

- 発熱するA→B機構をNASA上限直下から進め、範囲違反時にT/Yが変更されないこと。
- CFD全段の再試行後、採用刻みで初めから解いた結果と一致すること。
- 輸送テーブル下限直上からの膨張で、段棄却・刻み縮小・流束の巻戻しを確認。
- 不正な特性／流入境界候補が呼出し元を更新せず失敗を返すこと。
- 運動量・生成エネルギー込みの全エネルギーを化学で二重加算しないこと。

`rf_unit` と `rf_flow_unit` に追加し、Release/Debugで合格した。

## 温度反転

エネルギーからの温度反転は、NASA範囲を保つNewton法と二分法の組合せへ変更した。
Newton候補が区間外・非有限・停滞なら二分法に戻る。
収束許容誤差、端点の丸め許容幅、不連続多項式の拒否条件は従来どおり。
NASA端点とギャップを含む単体試験、および独立基準との回帰を維持する。

## 未対応を隠さない

全ての致命的エラーを捕捉する汎用例外処理ではない。
反応速度のオーバーフロー、無効なNASA係数やcp、輸送式の算術オーバーフロー等は依然停止し得る。
強い衝撃波での正値性や任意時間の安定性が証明されたことにはならない。
