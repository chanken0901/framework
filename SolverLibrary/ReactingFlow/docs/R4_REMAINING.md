## R4に残る大項目

1. **輸送・物性**: 温度・圧力・組成依存の混合平均拡散、物性データ取込み拡充、基準実装との比較。
   粘性と熱伝導は近似モデルまで。種名付きSutherland入力は追加済みだが、
   Cantera/CHEMKIN輸送データの自動取込みや衝突積分ベースの詳細モデルは未実装。
2. **境界と頑健性**: 特性／無反射境界、強い反応衝撃波の正値性・段棄却・境界反射の検証。
   局所線形特性流出境界の小振幅音響試験は追加済み。完全な反応性NSCBCは未実装。
   固定状態境界と限定的な化学積分の刻み再試行は追加済み。
   RHS物性範囲外などを含む汎用リカバリーは未実装。[再試行の範囲](CHEMISTRY_RETRY.md)
3. **1D反応波・デトネーション**: 同じ機構と上流状態でCJ速度・ZND構造を独立基準と比較。
   格子・時間刻み・化学許容誤差・分割誤差を切り分け、過駆動波と自走波を区別する。
4. **多次元・形状**: 2D/3D保存則、一般座標・ノズル、壁と流入出の検証。
5. **移行全体の比較**: 旧CFDとの対応条件で非反応／反応の比較、入力と保存量の意味の整合、回帰試験の整理。

推奨順は輸送・境界の拡充 → 1D反応波検証 → 多次元・ノズル → 全体比較。
実装は存在することと、実用条件で検証済みであることを区別する。
現時点で「R4はあと少し」「完成まで何％」とは評価しない。上記5領域にまとまった作業が残る。
検証で数値方式の見直しが必要になる可能性があり、正確な所要時間・会話回数は未見積り。
