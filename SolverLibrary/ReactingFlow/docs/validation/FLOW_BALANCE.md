# Fortranによる反応流の離散残差診断

`rf_flow_balance`は、初期分布に対する移流項と反応源を別々に評価する。
時間発展、保存量補正、クリッピングは行わない。R4の定常反応波検証用。

## 実行

通常のReactingFlowビルドで生成される。入力は`RF_FLOW_PROFILE_V1`形式で、
格子数・領域長・機構ハッシュをファイルから読む。指定した機構と一致する必要がある。
`muscl`または`first_order`を指定し、未使用の出力ファイル名を与える。

PowerShell（FrameWorkルート）：

```powershell
.\build\reactingflow-fortran-release\rf_flow_balance.exe m.rf initial.rf muscl balance.csv
```

Linux bash：

```bash
./build/reactingflow-fortran-release/rf_flow_balance m.rf initial.rf muscl balance.csv
```

前回保存した`build/reactingflow-extended-wave-refinement/`の条件フォルダ内の
`m.rf`と`initial.rf`も使用できる。ファイルの絶対パスを指定してよい。

## 出力の意味

保存量q=(ρY₁,…,ρYₙ,ρu,ρE)に対し、

```
advection = -(F_(i+1/2) - F_(i-1/2)) / dx
chemistry = (ω₁,…,ωₙ,0,0)
residual = advection + chemistry
```

を計算する。移流流束とMUSCL再構築はCFD本体と同じ実装を呼ぶ。
ωは質量生成率[kg/(m³ s)]。運動量残差は[kg/(m² s²)]、エネルギー残差は[W/m³]。
全エネルギーに生成エネルギーを含むので、別の反応熱源を足さない。

CSVにはx、ρ、u、T、p、物理的な質量・運動量・エネルギー流束と、
各保存量の`advection_*`、`chemistry_*`、`residual_*`を出す。
物理流束列と、数値流束から作る移流残差は区別する。
定常連続解でも数値残差がゼロになるとは限らず、格子収束を調べる必要がある。

**境界は診断専用の両端outflow、粘性・熱伝導・拡散は含まない。**
内部比較では少なくとも両端各2セルを除外する。
実計算の流入・特性境界における残差を再現する診断ではない。
時間積分・反応分割誤差もこの出力だけでは評価しない。

## 2026-10-01の切り分けと修正

独立Cantera評価では初期ZNDの物理流束は約1e-12の相対誤差で一定、
FortranとCanteraの反応源の最大相対差は約6e-14以下だった。
一方、MUSCL再構築において、最も多い化学種（一定濃度のN2）を組成傾きの
総和補正先に選ぶと、その局所上下限が同じため全化学種の傾きがゼロになり得た。

補正先を、最も多い成分ではなく**局所変動幅が最大の成分**へ変更した。
質量分率和、局所上下限、非負性を維持し、一定濃度の不活性成分を不要に変えない。
濃度・反応速度・保存量のクリッピングは追加していない。
一定濃度の主成分と3つの変動成分を使った回帰試験で再発を防ぐ。

初期分布のx=0.6〜1.9 mmにおける指標：

| セル数 | 最大化学種残差／最大反応源：修正前→後 | エネルギー残差L1×領域長／最大エネルギー流束：修正前→後 |
|---:|---:|---:|
| 128 | 0.8534 → 0.4404 | 0.9631 → 0.2248 |
| 256 | 0.4471 → 0.1177 | 0.5313 → 0.07278 |
| 512 | 0.2453 → 0.02072 | 0.2790 → 0.009852 |

この表は滑らかな内部区間の離散残差で、CFD解の時間発展誤差そのものではない。
1.0 µsの実際の再計算結果は[延長試験報告](EXTENDED_WAVE_VALIDATION.md)を参照。
